# 최종 발표·결과팀 인계

이 폴더만 읽어도 특허분석 결과와 다음 평가 과정을 파악할 수 있습니다. 기준일 2026-11-18.

1. **[결과팀 인계서](결과팀_인계.md)** — 결론, 정량 결과, 삼성물산 기술 기반, 비교할 사업 대안과 평가 입력.
2. **[도표 미리보기](figures/README.md)** — 본문 7개·부록 2개. 07은 참고용 Logistic·Gompertz 곡선. PNG는 장표 삽입용, `editable/`의 SVG는 편집용.
3. **[발표 대본](발표대본.md)** — 도표 번호별 설명과 예상 질문.
4. [미국 특허 20건 청구항 분석](미국특허_20건_청구항분석.md) — 독립항 1의 구성, 원문 링크, 기능 코딩 기준.
5. [팀 공유 메시지](팀_공유메시지.md) — 결과팀에 전달할 존댓말 문안.

정확한 검색식은 [검색 기준](../docs/검색기준.md), 판정 수정과 계산 확인은 [검증 기록](../docs/검증기록.md), 행별 수치는 [계산 결과](../data/results/final/)에 있습니다.

전체 발표 덱의 페이지 번호는 별도로 맞춰주세요. 이 폴더의 그림 번호와 대본 번호는 서로 대응합니다.

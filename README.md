## 분석을 사용할 때

**V2 검토 브랜치:** 팀원1 담당 미국 분석을 키워드 + CPC 검색(V2)으로 바꿨습니다. V2 기준은 DLC 1,874·액침 658 패밀리이며 37개는 중복입니다(키워드만 쓴 main 기준은 DLC 447·액침 163). 핵심특허 20건도 V2 데이터로 다시 뽑아 청구항 1을 코딩했습니다(팀원2 검토 대기). 국내·자사 분석은 main과 같습니다. 무엇이 바뀌었는지는 [인계서 2-1절 '검색식 보완과 V2'](deliverables/결과팀_인계.md)에 있습니다. 특허활동·청구항 비교 결과를 시장점유율이나 성능·비용 우위로 해석하지 않습니다. S커브 단계 판정과 특허 수에 따른 자동 AHP 점수는 사용하지 않았습니다. 자세한 범위와 한계는 [인계서](deliverables/결과팀_인계.md)에 있습니다.

이전 팀원별 자료는 `archive/`에 보존했습니다. 발표에는 `deliverables/`의 최신 도표를 사용하세요. 강의 녹음·다른 학생의 발표 원본·비공개 문서 전체 사본·인증 정보는 포함하지 않습니다.

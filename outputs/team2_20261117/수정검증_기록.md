## 재현과 파일 관계

1. `analysis/fetch_claims_20261117.py`: 공개 원문에서 청구항을 수집·정규화. 기존 JSON은 캐시를 사용한다. 파일마다 URL·확인일·수집 HTML 해시 포함.
2. `analysis/complete_analysis_20261117.py`: 원본 CSV에서 추가 제외, 기간 합계·HHI·CR4·CPC·민감도 계산. 원래 Excel은 S커브 검증값을 읽는 용도로만 사용.
3. `analysis/code_claims_20261117.py`: 검토자가 부여한 기능 코딩으로 20행 CSV·상세 MD·집계 JSON 생성. 자동으로 법적 범위를 판단한 것이 아님.
4. `analysis/figures_20261117.py`: 위 계산 결과로 8개 PNG·SVG 생성. 기능 코딩/범위를 바꾸면 순서대로 재실행.
5. `analysis/validate_20261118.py`: 합계·분모·표본·행별 근거·그림 파일과 변경되지 않은 원본 해시 검증.

`analysis.json`에는 입력 CSV 해시, `metrics_comparison.csv`에는 원본/재검토/경계 제외 값을 보존했다. `US_claim1_review_20.csv`는 원문 링크와 코딩 근거를 포함한다. 같은 폴더의 수치를 기준으로 사용하고 기존 팀원1 그림과 일부 수치만 섞지 않는다.

## 아직 가능한 주장과 보류할 주장

사용 가능: 검색범위 안의 특허활동 증가, 출원 분포, 기능군 변화, 선정 청구항의 반복 기능, 삼성물산 공동개발 참여, 비교할 확보 방식.

보류: 산업 전체 특허 총수·재현율, 시장점유율, 성숙도/남은 수명 확정, 시설 통합 시장의 공백, 침해·자유실시 결론, 액침/DLC의 성능·비용 순위, 계약 접근권과 실측값 없는 AHP 최종 순위.

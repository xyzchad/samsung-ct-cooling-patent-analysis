# 분석 재현

명령은 저장소 루트에서 실행합니다. 최신 코드의 경로 정의는 [src/final/paths.py](../src/final/paths.py)에 모았습니다.

```bash
python3 -m pip install -r requirements.txt
python3 src/final/fetch_claims.py
python3 src/final/analyze_patents.py
python3 src/final/review_claims.py
python3 src/final/render_figures.py
python3 src/final/validate.py
python3 src/maintenance/check_repository.py
```

`fetch_claims.py`는 기존 [청구항 캐시](../data/raw/patent_claims/)가 있으면 네트워크를 사용하지 않습니다. 나머지는 보존된 입력으로 계산합니다. 계산 결과는 `data/results/final/`, 추가 검토 패밀리는 `data/processed/us_reviewed/`, 발표 그림은 `deliverables/figures/`, 검증은 `docs/validation/`에 저장합니다.

기능군 정의와 관련성 판정은 `analyze_patents.py`, 독립항 1의 수작업 기능 코딩은 `review_claims.py`에 있습니다. 정의나 코딩을 바꾸면 계산·그림·해석을 함께 갱신해야 합니다. 청구항 JSON의 `document_dates_metadata`는 최초 우선일 필드가 아닙니다.

그림은 macOS의 Apple SD Gothic Neo를 사용합니다. 다른 OS에서는 설치된 한글 글꼴을 지정하고 출력의 한글·줄바꿈을 확인하세요. 도표 내용은 PNG, 확대·편집은 `figures/editable/`의 SVG를 사용합니다.

## 이전 분석의 재현

팀원1의 원래 정량분석 코드는 [src/us_baseline/](../src/us_baseline/)에 있습니다. 각 스크립트가 자기 위치에서 경로를 해석하므로 루트에서 실행할 수 있습니다. `clean.py` → `build_core_list.py` → `run_analysis.py` → `specialists.py` → `facility.py` 순서이며, 실행하면 보존된 기준본·Excel을 다시 작성할 수 있으므로 의도적으로 재생성할 때만 사용하세요. 판정 해석은 [최종 인계서](../deliverables/결과팀_인계.md)가 기준입니다.

읽기·일치 검증만 하려면:

```bash
python3 src/us_baseline/validate.py
node src/kr/validate_supplement.mjs
```

국내의 예전 Excel·그림 생성기는 [src/kr/](../src/kr/)에 보존했습니다. Excel 생성기는 원래 작성 환경의 `@oai/artifact-tool`, 그림 생성기는 Playwright·Chromium이 필요합니다. 근거 Excel과 PNG는 이미 포함되어 있어 인계서 열람에는 이 환경이 필요하지 않습니다.
